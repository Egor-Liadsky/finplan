## Задание

1. **`account_movements`.** Сумма движений по каждому счёту в валюте
   счёта: доход прибавляется, расход и перевод вычитаются, учитываются
   только `posted`; сторнированная операция вместе со своей сторнирующей
   записью в сумме не отражается. Суммы сравниваются как `Decimal`
   точно, без округления и без `float`.

2. **`totals_by_category`.** Суммы `base_amount` по категориям за
   период: операция ровно в момент `start` входит, ровно в момент `end`
   не входит (полуинтервал `[from, to)`); операции без категории, не
   `posted` и других видов не учитываются; доходы и расходы разделены.

3. **Изоляция, раздел 11.4.** Параметризованный тест, который перебирает
   все публичные методы четырёх репозиториев и `SqlAlchemyLedgerQueries`,
   получая список методов автоматически (например, через `inspect` по
   классу, без приватных методов), и требует, чтобы под Unit of Work
   пользователя B данные пользователя A не возвращались: `get` даёт
   `None`, `list` и агрегаты не содержат объектов A, а `mark_reversed` с
   чужим идентификатором не меняет операцию A. Метод, для которого
   способ проверки не описан в таблице теста, должен ронять тест, а не
   пропускаться молча, — иначе новый метод можно добавить без проверки
   изоляции. Отдельно проверить, что без явного фильтра по `user_id`
   чужие строки отсекает сама RLS: прямой `SELECT` из `transactions` под
   `finplan_app` с `app.user_id` пользователя B не возвращает строк A.

Все тесты помечаются `pytestmark = pytest.mark.integration`.

## Границы

- `src/` и `migrations/` не изменяются: `git diff --stat -- src
  migrations` пуст. Найденный дефект продуктового кода не чинить, а
  описать в результате с `file:line` и тестом, помеченным
  `pytest.mark.xfail(strict=True, reason=...)`.
- Фикстуры из `tests/integration/repositories/conftest.py` расширять
  можно, менять поведение существующих — нет: на них держатся тесты
  первой части.
- `tests/conftest.py` не изменяется.
- Новые зависимости не добавляются.

## Критерий приёмки

- `uv run pytest tests/integration/repositories -q` зелёный при
  работающем Docker; число тестов названо в результате;
- `make test` зелёный целиком;
- `uv run ruff check` и `uv run ruff format --check` чистые;
- параметризованный тест изоляции получает список методов автоматически
  и падает на методе без описанной проверки — это показано в результате
  (например, временным методом-заглушкой в тесте, который потом убран);
- есть тест на границы полуинтервала `[start, end)`;
- `git diff --stat -- src migrations` пуст.
