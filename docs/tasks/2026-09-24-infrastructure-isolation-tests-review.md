## Задание

Проверить дифф по списку «Что искать» из роли `reviewer` с упором на
изоляцию и запросы:

- 11.4 выполнен: параметризованный тест действительно собирает все
  публичные методы репозиториев и запросов журнала и падает на новом
  методе без описанной проверки; сбор не пропускает методы, объявленные
  в базовом классе или добавленные позже; проверка каждого метода
  утверждает отсутствие чужих данных, а не отсутствие исключения;
- тест проходил бы красным, если бы RLS не работал: проверить, что
  данные «соседа» видны владельцу соединения до смены `app.user_id`, то
  есть тест не проходит из-за невидимости некоммиченных строк;
- прямой `SELECT` без фильтра по `user_id` идёт под ролью `finplan_app`
  и проверяет отсечение чужих строк именно политикой;
- отказ RLS на запись с чужим `user_id` проверяется по коду `42501`, а не
  по любому исключению;
- исключение для поиска по `telegram_id` до аутентификации по 4.5
  оформлено явно и не маскирует дыру в изоляции других методов;
- запросы журнала: суммы точные в `Decimal`, сторнированные пары
  исключены по статусу, границы полуинтервала `[start, end)` проверены
  операцией ровно в `start` и ровно в `end`, суммы разных валют не
  складываются;
- `float` нигде не появляется, в том числе в литералах сумм;
- нет тестов, проходящих при любом поведении кода.

Известное и уже учтённое находкой не повторять:

- владелец данных и «сосед» работают на одном соединении намеренно:
  вариант с раздельными соединениями отвергнут, потому что при
  некоммиченной внешней транзакции тест проходил бы и без RLS;
- `get_by_telegram_id` изолирован иначе по 4.5 намеренно;
- переводов на этапе 1 нет, представление кросс-валютной пары — открытый
  вопрос 3.3;
- `make lint` не проверяет `mypy` каталог `tests/`.

Каждую находку отнести к одному из уровней:

- **нарушение** — тест проверяет не то, что требует `docs/architecture.md`,
  проходит без работающего RLS, или правило раздела 11 не выполнено;
  блокирует отметку подзадачи 11;
- **замечание** — тест корректен, но есть реальный риск, что дефект
  проскочит на следующих подзадачах этапа 1; назвать, на какой подзадаче
  плана он проявится;
- **к документу** — тест прав, а документ устарел или молчит; адресуется
  диспетчеру для правки документа.
