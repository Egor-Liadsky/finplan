## Задание

Проверить дифф по списку «Что искать» из роли `reviewer` с упором на
доступ к данным:

- реализации удовлетворяют протоколам из `application/ports/` не только
  по сигнатурам, но и по поведению: что возвращается при отсутствии
  строки, какие ошибки приложения (`DuplicateError`, `NotFoundError`)
  поднимаются вместо исключений SQLAlchemy и драйвера;
- Unit of Work по 2.2 и 4.5: `app.user_id` выставляется через
  `set_config(..., true)` в той же транзакции до первого запроса; `commit`
  без явного вызова не происходит; после `rollback` или исключения
  сессия не продолжает работу без `app.user_id`. Последний пункт — открытый
  вопрос из подзадачи 9a: RLS в этом случае вернёт пустой результат, а не
  чужие данные, но требуется ответ, возможно ли такое продолжение в
  текущем коде, с `file:line` и уровнем;
- поиск пользователя по `telegram_id` до аутентификации идёт только через
  функцию из 4.5 и не открывает доступ к чужим строкам;
- деньги: `Decimal` и `Money` на границе репозитория в обе стороны, нет
  `float`, нет потери валюты или масштаба при чтении `NUMERIC`;
- журнал по 4.2: репозиторий операций не делает `UPDATE` ничего, кроме
  перехода статуса в `reversed`, и не делает `DELETE`; сторнирующая запись
  по абзацу «Форма сторно» 3.3;
- `occurred_on` по 3.3 и 4.3: домен вычисляет, репозиторий пишет и
  читает готовое поле, таймзоны в инфраструктуре нет;
- запросы журнала: остаток по формуле 5.7 и сводки только по
  `status = posted`, период — полуинтервал `[start, end)`, суммы не
  складываются через разные валюты;
- 12.1: нет логирования сумм, описаний операций и других персональных
  данных сверх разрешённого;
- правка `occurred_on` в `domain` и `application` не нарушает 2.2:
  `domain` без IO и сторонних библиотек, `application` получает таймзону
  из `User.timezone` и не читает часы мимо `Clock`.

Известное и уже учтённое находкой не повторять:

- формула остатка и `LedgerQueries.account_movements` написаны для
  перевода одной строкой; представление кросс-валютной пары — открытый
  вопрос 3.3, решается на этапе 2;
- отчёты этапа 1 берут период по `occurred_at`, а не `occurred_on`; это
  записано в журнале решением подзадачи 9c;
- `make lint` не проверяет `mypy` каталог `tests/`.

Каждую находку отнести к одному из уровней:

- **нарушение** — противоречит `docs/architecture.md` или правилу слоёв,

- **замечание** — поведение корректно по документу, но есть реальный риск

- **к документу** — код прав, а документ устарел или молчит; адресуется
